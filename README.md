## 🚀 Sida Loo Isticmaalo Application-ka

### 1. Windows Desktop Application (Computer-ka):
* **Habka 1 (Ugu Fudud - 1 Gujin):**
  * Galka dhexdiisa ka hel faylka [`Start-App.bat`](file:///c:/Users/KCT/Desktop/bilan%20work%20shop/Start-App.bat) oo laba jeer ku dhufo.
  * Wuxuu ku furmayaa sidii **Desktop Application gaar ah** oo leh daaqad u gooni ah (Standalone App Window), bilaa link ama baarkoodh web ah!
* **Habka 2 (Electron Desktop App):**
  * Ku dhufo terminal-ka: `npm.cmd start`

### 2. Mobile Application (Android & iPhone):
* Markaad website-ka ka furto Chrome, Edge ama Safari ee taleefankaaga, waxaad arkeysaa badhanka **"Ku Shubo Mobile-ka (Install App)"** ama banner-ka hoose.
* Markaad riixdo, wuxuu toos ugu degayaa shaashadda hore ee taleefankaaga isagoo leh calaamadda (Icon-ka) rasmiga ah ee **Bilan Workshop**.
* Wuxuu leeyahay **Bottom Navigation Bar** casri ah oo u eg apps-ka caalamiga ah.
